# 全分类 Hurl 覆盖测试

## 本机实际配置

执行命令（Windows 使用 Hurl 自身的 glob）：

```powershell
hurl --test --jobs 1 --continue-on-error --path-as-is --noproxy "*" --connect-timeout 2 --max-time 5 --variable base_url=http://localhost --glob "tests/hurl-security/cases/*.hurl"
```

执行 21 个文件、4290 次请求，耗时 34.456 秒，成功文件 0，失败文件 21。测试前首页为 200，但运行过程中正常对照也返回 403，因此不能将这些 403 统计成内容检测成功。现有 CC/IP 封禁等策略及上游是否支持 `/probe` 会影响结果；未修改运行配置或解除封禁。

原始日志：`artifacts/hurl-security/localhost-all.log`；JUnit：`artifacts/hurl-security/localhost-all-junit.xml`。
