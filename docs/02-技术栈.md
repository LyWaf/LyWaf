## 技术选型关系

Kestrel 提供监听与 TLS，YARP 负责路由、目标选择和代理转发，LyWaf 中间件在 YARP 前后实现安全与流量功能。DuckDB 用于本地分析，不参与每个请求的同步判定；高频请求状态优先保存在并发内存结构中，再批量刷入数据库。

Vue 控制台通过 Axios 调用控制端 REST API。Pinia只保存跨页面状态，插件页面和局部表单优先使用组件内状态，避免把所有数据都提升为全局状态。

## 版本管理原则

表中版本以项目文件和锁文件为准，升级时应检查：

- .NET 目标框架与部署机 Runtime 是否一致。
- YARP 更新是否改变路由、Transform 或健康检查行为。
- DuckDB 原生库是否支持目标操作系统和架构。
- Vue、TypeScript 和 Vite 是否能完整通过生产构建。
- 外部插件引用的宿主契约版本是否兼容。

## 查看实际版本

```powershell
dotnet --info
dotnet list package
cd Frontend
npm list --depth=0
```

排障时应记录操作系统、CPU 架构、.NET Runtime、LyWaf 版本和配置摘要，仅报告“最新版”通常无法复现问题。
