# 安全特性

| 特性 | 说明 |
|------|------|
| JWT 认证 | 控制台 API 的令牌认证 |
| Basic Auth | HTTP 基础认证，兼容 CLI/curl |
| localhost 绑定 | 控制台默认仅绑定本机 |
| IP 访问控制 | 黑白名单 + CIDR 子网支持 |
| 地理封锁 | IP2Region 国家/地区级别封锁 |
| HTTPS 强制 | 自动 HTTP → HTTPS 重定向 |
| Let's Encrypt | 自动化证书签发与续期 |
| 验证码 | 可疑流量触发 Challenge-Response |
| 审计日志 | 控制台操作全量审计 |
| 限速 | 按 IP、按路径、全局限速 |
| 连接数限制 | 单 IP 最大并发连接 |
| WAF 规则 | 正则攻击模式检测 |
| CC 防护 | 行为分析 + 自动封禁 |
| 抓包隔离 | HTTPS 拦截使用独立 CA 证书 |
