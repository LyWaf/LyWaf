# 安全特性

| 特性 | 说明 |
|------|------|
| JWT 认证 | 控制台 API 的令牌认证 |
| Basic Auth | HTTP 基础认证，兼容 CLI/curl |
| localhost 绑定 | 控制台默认仅绑定本机 |
| IP 访问控制 | 黑白名单 + CIDR 子网支持 |
| IP 组 | IPv4/IPv6/CIDR 集中分组和复用 |
| 地理封锁 | IP2Region 国家/地区级别封锁 |
| HTTPS 强制 | 自动 HTTP → HTTPS 重定向 |
| Let's Encrypt | 自动化证书签发与续期 |
| 验证码 | 可疑流量触发 Challenge-Response |
| 审计日志 | 控制台操作全量审计 |
| 限速 | 按 IP、按路径、全局限速 |
| 连接数限制 | 单 IP 最大并发连接 |
| WAF 规则 | 正则攻击模式检测 |
| CC 防护 | 行为分析 + 自动封禁 |
| 抓包隔离 | HTTPS 拦截使用独立 CA 证书 |
| 网页防篡改 | 安全基线、目录收集、差异确认与排除 |
| CORS | 路由级 Origin 授权和预检短路 |

## 分层防护思路

安全配置应从最外层逐步收紧：先限制控制端暴露和恢复真实客户端 IP，再配置访问控制、WAF、CC 与限速，最后加入验证码和自动封禁。未经观察直接启用强阻断容易误伤正常请求。

## 默认安全基线

- 控制端只绑定管理网络或本机，并启用强认证。
- 公网业务强制 HTTPS，私钥仅服务账号可读。
- 仅信任明确的上游代理所写真实 IP 请求头。
- WAF 和 CC 先观察后阻断，保留误报回滚方式。
- CORS 使用精确 Origin，凭据模式禁止通配来源。
- 配置、认证文件、DuckDB 和插件数据定期备份。
- 管理操作写入审计日志并设置保留周期。

## 验证与响应

使用正常流量、典型攻击样本、OPTIONS 预检、大请求和高频请求分别验证。拦截事件应能回答“谁、何时、命中什么规则、采取什么动作”。发现误报时优先缩小规则范围或添加精确例外，不要直接关闭整个安全层。

LyWaf 只能处理已到达本机的流量。链路被打满、主机资源耗尽或上游凭据泄露仍需网络层和运维体系配合。
