# 备份任务与通知运维

本篇介绍管理端运维入口、实际保存范围，以及失败后的处理方式。所有接口均使用 `/api/v1` 前缀。备份模块保留登录、`system.manage` 权限和审计，但不再要求二次登录密码验证；其它敏感模块的二次认证不变。

## 任务中心

任务中心统一展示队列、执行状态、有限长度日志、取消和重试。证书签发、规则包下载、站点发布、升级包准备、配置与统计备份和节点同步已接入。

配置编辑器的“保存并重载”和历史回滚也返回 202 与 `data.id`，受理不是发布成功。任务执行重载校验，失败时恢复此前版本；首次创建的无效草稿会移除。版本历史保留原始操作者，需重启的字段记录在任务日志中。只保存草稿仍为同步操作。

程序激活和回退同样进入任务中心。候选就绪且持久化接管指针后开始排空，此时取消不撤销已经提交的接管；旧进程退出前停止接收任务并取消未执行项。旧任务记录不跨进程保留，最终是否切换成功应以启动日志和版本列表为准。

| 入口 | 作用 |
| --- | --- |
| `POST /api/v1/tasks/certificate` | 提交 `domain`、`email`，后台签发证书 |
| `POST /api/v1/tasks/upgrade-stage` | 提交 `packageName`、`version`、`sha256`，校验并准备升级包 |
| `GET /api/v1/tasks` | 按状态、类型分页查询 |
| `GET /api/v1/tasks/{id}` | 查询日志和终态 |
| `POST /api/v1/tasks/{id}/cancel` | 请求协作取消 |
| `POST /api/v1/tasks/{id}/retry` | 为失败、取消或超时任务创建新任务 |

升级准备成功不表示已经切换程序版本。取消和超时也不会强杀线程，任务执行器退出后才确认终态，避免界面显示取消后仍在写配置。

设置页面的 `settings/certs/acme-apply`、`settings/certs/acme-renew` 以及 `upgrade/stage` 同样返回 202 和 `data.id`，不再同步等待远端 CA 或候选程序校验。页面提交后进入任务详情；旧脚本需改为轮询终态后读取证书或版本列表。

当前队列为单工作线程、64 项排队容量，最多保留 200 项终态记录，每项最多 100 条日志。记录保存在当前进程内；重启后的自动续跑尚未实现。不要把进程内任务 ID 当作长期审计档案。

执行器正常返回表示操作已经完成，队列不会因迟到的取消把成功结果改为可重试的取消状态。执行器在提交前应检查令牌，并在真正取消时抛出取消异常；提交后不能仅因令牌变化而报告未完成。忽略令牌的第三方操作无法被安全强制终止，界面应以最终执行结果为准。

## 配置备份

页面入口为“备份恢复”，可选择配置、统计数据库或实例状态。配置范围是主配置、同目录草稿及 `.lywaf.lb-patch.json`；统计数据库与实例状态使用独立备份包。三个范围分别保存，程序二进制、外部插件安装包和站点源文件不属于备份范围，不要据此删除原安装目录。

1. 选择备份范围并创建任务，无需填写备份密码。
2. 在任务中心确认成功，回到备份列表刷新后下载 `.lybackup`。
3. 恢复前执行预检；预检不写回文件。
4. 确认备份范围与运行实例一致后执行恢复，并检查恢复任务日志。

备份文件保存于主配置目录的 `.lywaf.backups`，最多保留 100 份。配置备份上传限制为 32 MiB。新的免密码备份不加密，可能包含账号和私钥，必须限制目录权限并妥善保管下载文件。旧加密包可通过 API 提交原 `password` 预检和恢复，原密码丢失仍无法解密。

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/backups` | 列出备份 ID、大小与时间，不返回服务器路径 |
| `POST /api/v1/backups` | `{ "scope": "configuration" }`，返回任务 ID，无需密码 |
| `POST /api/v1/backups/upload` | 原始二进制请求体，上传后仍需预检 |
| `GET /api/v1/backups/{id}/download` | 流式下载，支持范围请求，禁止缓存 |
| `POST /api/v1/backups/{id}/preflight` | 请求体 `{}`，验证清单、摘要与候选配置；旧加密包另外提交原 `password` |
| `POST /api/v1/backups/{id}/restore` | 预检后原子替换并重载，失败则回滚 |
| `DELETE /api/v1/backups/{id}` | 删除指定备份，写审计记录 |

### 加密与内存边界

默认免密码容器版本为 `LYWAFBP1`，采用流式复制，保留清单、摘要、路径白名单、容量限制及失败回滚。摘要用于检测损坏，不提供来源认证。下述 `LYWAFBK1` 加密说明仅适用于通过 API 显式提交密码的兼容模式；页面不创建加密包。

容器版本为 `LYWAFBK1`。密码通过 PBKDF2-SHA256 派生密钥，随机盐与每块独立的 AES-GCM 认证保护内容。每块最多 64 KiB，块序号进入认证数据；末尾还有认证终止块，因此截断、替换或重排不能被当作完整备份。

文件经临时文件及流处理，不一次性读取整个归档。归档具有版本、逻辑文件名、长度、SHA256 和修改时间清单；恢复端只将逻辑名映射到已知目标，不直接使用归档内路径。修改时间也被恢复，避免主配置时间变化导致运行时补丁的来源检查失效。

通用归档引擎最多接受 1000 个文件、单文件 512 MiB、总内容 4 GiB；配置页面还有更严格的限制。配置语义预检需要解析文本，单份配置限制为 8 MiB。临时目录需要足够空间，包含解密后的暂存文件，操作完成后清理；磁盘加密和目录访问控制仍由部署环境负责。

### 失败处理

错误密码、认证失败、重复条目、路径穿越、未知逻辑文件或不兼容版本会在写回前被拒绝。若现有草稿或补丁未包含在备份中，恢复也会拒绝，避免旧文件覆盖恢复结果。

写入或重载失败后按相反顺序恢复旧文件。若连回滚也失败，旧副本保留在错误记录指明的暂存目录，不能直接清理。涉及监听、数据库和其他进程级字段时，恢复日志会提示仍需重启；热重载成功不等于这些字段已经生效。

### 统计数据库备份与恢复

创建时提交 `scope: "statistics"`，上传统计备份时使用 `?scope=statistics`。列表中的 `scope` 标识包类型，统计包 ID 以 `s-` 开头；两种备份不能混用。统计包压缩加密后最多 32 MiB，解包数据库最多 512 MiB。全局管理 API 请求体限制如果更低，仍以该限制为准。

快照通过独立 DuckDB 连接，在事务中执行 `COPY FROM DATABASE` 并检查点落盘，再流式加密打包。它包含已提交的统计数据及表结构，不包含尚在内存中、未刷写的最新计数，不直接复制活动数据库文件或 WAL。参见 [DuckDB 数据库复制](https://duckdb.org/docs/current/sql/statements/copy#copy-from-database--to)。

统计恢复分两阶段：后台校验密码、摘要、版本及必需表结构，成功后登记待执行任务；下一次正常启动且启用 DuckDB 时，在统计恢复和写入服务之前替换数据库。当前进程的数据不会被中途替换。页面显示“待重启执行”，可用 `DELETE /api/v1/backups/statistics-pending` 取消。登记任务成功只表示准备完成，实际恢复结果记录在启动日志中。

待执行归档为加密副本，密码登记由专用 Data Protection 密钥保护。数据库路径在登记后发生变化时拒绝恢复；另一个实例持有同数据库运行锁、旧库无法正常检查点或仍有 WAL 时也不会覆盖。归档预检失败不修改数据库，文件替换失败使用原副本回滚。恢复失败会阻止启动，需排除错误后重试，不能静默启动空库。

## 实例状态冷备份

选择“实例状态（需重启）”或提交 `scope: "instance"`，包 ID 以 `i-` 开头。包含管理账号/角色/MFA 状态、管理令牌、通知配置、站点及事件状态、Data Protection 密钥、插件数据目录、ACME/内部 CA 目录，以及 `WafInfos.Certs` 指定的证书和私钥文件。上传时也需选择该范围。

创建任务只登记操作，备份文件在下一次正常启动、任何状态服务加载前生成。因此快照时间是下次启动时，而非点击按钮时。这个窗口中没有本实例的插件写入，不会把活动数据库和不同时刻的 WAL 拼成备份。恢复同样先预检、登记，再在下次启动执行；覆盖范围内文件，并删除快照中已不存在的状态文件。文件替换或删除失败会按事务回滚。

启动前处理完成后才加载账号和插件，避免旧的内存对象覆盖已恢复数据。页面显示待执行状态，可用 `DELETE /api/v1/backups/instance-pending` 取消。目录配置变化、链接路径、损坏的备份或无可用管理员等问题会阻止恢复；启动失败时保留登记凭据，应修复问题后重试，或由运维删除配置目录下 `.lywaf.instance-pending` 及其 `.lybackup` 副本以取消。不要删除原始备份。

各实例须使用独立工作目录和状态目录；正常实例持有工作目录内的 `.lywaf.instance-state.lock`，同一工作目录不能同时启动两个写入实例。不同工作目录也不得共享插件/证书写入目录，文件系统外部写入者不受本进程锁控制。升级就绪探针不执行登记任务。

状态包仍遵守 1000 文件、单文件 512 MiB、总内容 4 GiB、最终加密包 32 MiB 的限制；超限明确失败，不静默遗漏。按同版本程序、相同插件集合恢复；外部插件自身的数据兼容性、外部数据库、系统证书库和机器绑定的密钥不由文件归档替代。迁移到另一台机器前应验证密钥可解密，并保留原部署。

## 通知告警

“通知告警”支持 HTTPS Webhook、SMTP 邮件及插件发送器。渠道可按站点、攻击类型、累计次数阈值选择事件，配置合并窗口与静默截止时间。

- Webhook 使用 HTTPS，禁止自动重定向。
- SMTP 强制 TLS；密码使用本机 Data Protection 密钥保护，查询接口不返回密码或密文。
- 插件必须处于运行状态，获准网络权限并实现 `IPluginNotificationSink`。
- 同一事件在合并窗口内累计，发送时只提交尚未送达的增量。
- 失败最多自动尝试 3 次，之后可在页面手动重试。

渠道配置持久化在 `.lywaf.notifications.json`，密钥位于 `.lywaf.keys`。发送队列当前不跨重启恢复，最多保留 512 个事件/渠道组合。不要承诺严格恰好一次投递：远端已接收但本地超时仍可能触发重试，接收方应利用通知 ID 去重。

## 单次事件下钻

事件详情里的“单次请求记录”查询滚动文件，而不是仅显示聚合对象中的最近 3 个样本。每个文件最多 2 MiB，最多保留 8 个文件；队列最多 512 项，过载或磁盘错误会累计丢弃计数并展示。

记录包含请求 ID、方法、路径、命中字段、规范化步骤和少量参数名。不保存参数值、认证头、Cookie 或请求体原文。游标分页按时间和记录 ID 倒序，不一次读取所有记录。历史记录会随容量轮换，聚合次数可能大于当前保留记录数，这是明确的保留策略，不表示计数错误。

## 验证范围

自动化测试覆盖加密往返、错误密码、篡改、截断、重排、归档路径白名单、预检不写入、激活失败回滚、文件时间保留、记录分页和队列容量。独立本地实例验证了登录、二次认证、创建配置备份和预检成功；桌面与窄屏页面也进行了检查。

真实证书签发、SMTP 投递和外部插件通知需要对应环境和凭据，不能以本机单元测试替代上线验收。
