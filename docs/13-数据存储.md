# 数据存储

## 内存（线程安全）

- **ExpiringSafeDictionary<K,V>** — 带 TTL 自动过期的并发字典
- **ExpiringSafeDictList\<T>** — 支持滑动/绝对过期的列表变体
- **SharedData** — 全局字典：IP 统计、限制、缓存、拦截事件

## 持久化（DuckDB）

- 统计表：IP 统计、请求数、响应时间
- 访问日志：详细请求记录
- 审计日志：控制面操作历史
- 运行日志：服务事件
- 启动时自动建表（DuckDbSchema）
- 可配置数据保留策略

## 配置文件

| 文件 | 用途 |
|------|------|
| .lywaf.auth.json | 认证凭据 |
| .lywaf.rules.json | 自定义 WAF 规则 |
| .lywaf.generated.yaml | 生成的 YARP 配置状态 |
| .lywaf.statistic.json | 统计快照 |
| .lywaf.lb-patch.json | 负载均衡覆写补丁 |
