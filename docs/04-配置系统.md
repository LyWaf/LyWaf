# 配置系统

## LY 格式

LyWaf 使用自定义 DSL（受 Caddy 启发）作为主配置格式，同时支持 YAML 作为备选。

### 特性

- 变量替换与环境变量插值
- 花括号块作用域（类似 Caddy）
- `()` 语法定义可复用 snippet
- 文件变更时热更新（IOptionsMonitor）

## 配置段

| 配置段 | 用途 |
|--------|------|
| WafInfos | 监听地址、证书、控制台绑定 |
| ReverseProxy | 路由、集群、负载均衡策略 |
| FileServer | 静态文件服务 |
| SpeedLimit | 限速规则（令牌桶、滑动窗口） |
| Statistic | 统计采集与 CC 防护规则 |
| AccessControl | IP 黑白名单、地理封锁 |
| Compress | 响应压缩（gzip, brotli, zstd） |
| Acme | Let's Encrypt 证书自动化 |
| SimpleRes | Mock HTTP 响应定义 |
| CustomDns | DNS 覆写映射 |
| ProxyServer | HTTP/HTTPS/SOCKS5 代理设置 |
| StreamServer | TCP/UDP 流转发 |
| VpnServer | SoftEther VPN 配置 |
| Plugins | 插件专属配置 |

## 配置管线

```
config.ly → LyConfig（解析器）→ LyToYaml（转换器）→ YARP Configuration → 热更新
```

配置支持实时更新。config.ly 文件变更后通过 IOptionsMonitor 检测并传播到所有服务，无需重启。
