# 配置系统

## LY 格式

LyWaf 使用自定义 DSL（受 Caddy 启发）作为主配置格式，同时支持 YAML 作为备选。

### 特性

- 变量替换与环境变量插值
- 花括号块作用域（类似 Caddy）
- `()` 语法定义可复用 snippet
- 文件变更时热更新（IOptionsMonitor）

## 配置段

| 配置段 | 用途 |
|--------|------|
| WafInfos | 监听地址、证书、控制台绑定 |
| ReverseProxy | 路由、集群、负载均衡策略 |
| FileServer | 静态文件服务 |
| SpeedLimit | 限速规则（令牌桶、滑动窗口） |
| Statistic | 统计采集与 CC 防护规则 |
| AccessControl | IP 黑白名单、地理封锁 |
| Compress | 响应压缩（gzip、brotli） |
| Acme | 多 CA、按需签发、内部 CA、吊销状态与多节点签发锁 |
| SimpleRes | Mock HTTP 响应定义 |
| CustomDns | DNS 覆写映射 |
| ProxyServer | HTTP/HTTPS/SOCKS5 代理设置 |
| StreamServer | TCP/UDP 四层转发、SNI、PROXY Protocol 与访问控制 |
| Plugins | 插件专属配置 |
| Cors | 站点/路径级跨域策略（转换为路由元数据） |

## 配置管线

```
config.ly → LyConfig（解析器）→ LyToYaml（转换器）→ YARP Configuration → 热更新
```

部分 Options 配置支持变更通知；监听端口、Kestrel 和启动期插件注册等设置仍需要重启。生产变更后应从日志确认实际生效，不要假设所有配置均可无重启更新。

## 配置优先级与生成物

主配置经过解析后转换为 ASP.NET Core/YARP 可绑定的数据。控制台产生的补丁用于保存可视化修改，不应手工把生成文件当作唯一配置源。部署时应同时管理主配置、必要补丁和敏感文件，并明确哪一层拥有最终值。

## 安全修改流程

1. 备份当前 `config.ly` 和运行时补丁。
2. 在副本中修改并执行语法校验。
3. 对比生成配置，确认路由和监听未意外删除。
4. 应用重载并检查日志中的成功或错误。
5. 从本机和外部各发起一次健康请求。
6. 需要重启的设置安排维护窗口。

## 常见错误

- 花括号层级错误导致后续配置落入错误块。
- 域名携带 scheme，而字段实际只接受 host 或 `host:port`。
- 通配路径与 ASP.NET Core 路由模板语义混用。
- 环境变量为空后生成无效证书路径或上游地址。
- 误以为热更新会重建监听端口和中间件结构。
