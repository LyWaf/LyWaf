# 管理身份、站点发布与事件处置

## 身份与权限

旧管理员首次加载时迁移为用户记录。管理员拥有读、写、用户管理及系统管理权限；审计员只有读权限。后台可以创建业务角色，配置 `read`、`write`、`users.manage`、`system.manage`。角色或密码变更、禁用、撤销会话都会更新会话版本，使旧 JWT 失效。

控制端点声明权限，前端是否显示按钮不是授权依据。配置、管理凭据及服务生命周期操作要求系统管理权限。重载、重启和停止现改为 `POST /api/v1/reload`、`POST /api/v1/restart`、`POST /api/v1/stop`，旧 GET 不再执行操作。

在通用设置的控制台页绑定 TOTP 验证器，绑定后展示十个仅可使用一次的恢复码。服务端加密保存验证器密钥，仅保存恢复码摘要；密钥加密依赖 JWT 密钥，备份时必须一起保留。启用后 Basic Auth 不可用于该人员账号。动态码有重放保护，同一时间步已经使用的码不能再次验证。

人员执行敏感操作时，接口返回 HTTP 428，页面弹出二次验证。验证密码和已启用的 TOTP 后，签发绑定当前 JWT 的五分钟凭证。自动化 API Token 仍走独立权限验证，不冒充人员 MFA。

## 站点发布

站点管理以 YARP 路由 ID 为身份，保留原匹配、变换和集群引用。`.lywaf.sites.json` 存储覆盖及最近十个版本，不改写主配置。配置发现的路由也能暂停或删除，运行快照会移除对应路由，而不是只在页面隐藏。

每次修改创建后台任务，依次校验路由、原子保存、发布快照、核对 YARP 运行态版本。确认超时或取消时恢复发布前文件和快照，再确认回滚结果。编辑请求使用 `If-Match` 拒绝陈旧版本覆盖。任务失败时应检查任务日志，不能把“已入队”当作“已生效”。

复制站点不会复制上游服务器，而是保留集群引用。批量规则绑定仅筛选用户 WAF 规则，系统内置及配置规则不会被关闭。导出包依赖目标系统已有的集群与规则，导入校验会拒绝不存在的引用。

站点统计按本机日期计数，显示实际开始观测时间，每三十秒刷盘。非正常退出最多损失一个刷写周期的数据。证书状态来自现有证书管理，未托管证书不等于站点没有 TLS。

## 任务与健康

任务队列容量为 64，串行执行，最多保留 200 条终态任务。每个任务最多 100 行日志，每行最多 2000 字符。执行器必须协作取消：只有执行器退出后才确认取消或超时，避免后台仍然修改配置。当前任务记录不跨进程恢复。

健康页读取实际进程、YARP 上游检查、监听、证书、数据库和队列状态。读取数据库状态不会触发打开数据库；`initializing`、`disabled` 与 `ready` 有不同含义。

## 事件处置

事件按站点、域名、IP、规则和攻击类型生成稳定指纹。计数、首末时间与处置状态分离；相同攻击继续出现不会覆盖操作人的处置备注。处置使用独立版本号防止两个操作者相互覆盖。

默认最多保存 1000 个聚合事件，每个保留最近三个请求样本、十条处置记录。达到容量上限时显示未收录数量；完整历史仍应通过原拦截日志保留。样本不保存 Cookie、认证头、查询参数值及请求体原文。命中字段和已执行的规范化步骤来自检测过程，不重新读取请求体。

从事件可查看或调整对应规则，或在系统权限和二次验证后将 IP 加入全局黑白名单。添加白名单会影响该 IP 的所有站点，应谨慎使用。误报处置状态不自动改写规则，实际规则调整与处置记录是两项操作。

## 验证

运行 `dotnet test tests/LyWaf.Tests -c Release` 与前端 `npm run build`。新增测试覆盖角色撤销、TOTP 标准向量、恢复码、二次验证会话绑定、端点权限、任务取消与重试、真实 YARP 发布与回滚、事件聚合及处置持久化。
