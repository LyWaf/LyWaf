# 稳定管理 API 契约

本专题解释 LyWaf 如何让控制台、运维脚本和插件在升级时保持兼容。完整端点约定见 [管理 API 契约](11-REST-API.md)。

## 设计目标

管理 API 与代理流量完全分离，只在 `ControlListen` 生效。v1 公开地址统一使用 `/api/v1`，内部暂时复用原 `/api` 路由实现。`ManagementApiContract` 在路由匹配前完成版本转换，并为响应附加 API 版本和请求 ID。

统一安全准入还会在认证前施加请求体和来源频率限制，并在写请求完成后记录请求 ID 审计；配置项和远程监听授权见[Admin API 安全工作流](44-Admin-API安全工作流.md)。

## 兼容原则

1. v1 内可以增加端点、可选请求字段和可选响应字段。
2. 不改变已有字段类型、含义、默认值和成功状态码。
3. 破坏性变化进入 v2，v1 在公告废弃后至少保留 12 个月。
4. 旧无版本路径只用于迁移，通过 `Deprecation`、`Sunset` 和 `Link` 提示替代版本。

## 故障响应

统一错误由 `success=false`、兼容 `message` 和结构化 `error` 组成。`error.code` 面向程序判断，`traceId` 面向日志关联。未处理异常在服务端完整记录，但外部只得到 `internal_error`。

管理端点过滤器会为旧式 `success/message` 错误补充统一信封，并保留原业务字段。JSON DTO 在业务执行前进行非空、枚举和 DataAnnotations 校验，字段错误位于 `error.details`。插件自行定义的报文仍需插件负责语义校验。

## 列表参数

任务、站点、事件、备份、WAF/CC 规则、IP 组、用户、角色、登录历史、令牌、审计/运行日志、缓存和运行状态等资源列表采用以下约定：

| 参数 | 约束 |
| --- | --- |
| `page` | 从 1 开始 |
| `pageSize` | 1 至 100，默认 20 |
| `search` | 最多 200 字符，按该业务的公开字段搜索 |
| `sortBy` | 端点允许的排序字段，不接受任意属性表达式 |
| `sortDirection` | `asc` 或 `desc` |
| `from`、`to` | ISO 8601 时间；没有业务时间字段的列表拒绝时间筛选 |

响应包含 `success`、`data`、`total`、`page`、`pageSize`、`sortBy` 和 `sortDirection`。WAF 规则也使用 `data`，页面和脚本不要再读取旧的 `rules` 字段。`total` 是筛选后、分页前的条数。非法页码、重复参数、未知排序字段和倒置时间范围返回 400，而非静默修正。

时间字段不是统一的“创建时间”：事件按最后发生时间，IP 组按更新时间，用户和令牌按创建时间，登录历史按发生时间，缓存按写入时间，运行状态按变更时间。排序字段由各业务端点声明。

日志文件列表同样分页；日志正文按索引逐条读取。单条正文上限为 8 MiB，单页原始正文总量上限为 16 MiB，单文件索引上限为 100000 条。超过页面上限时应降低 `pageSize`；超过索引上限时先轮转或拆分日志。扫描响应请求取消，并且不追读打开文件后追加的内容。

历史图表、Top N 排名及配置选项集合不等同于资源分页表。历史图表保留时间序列结构，时间范围最多 366 天；流量、安全态势、QPS 和带宽最多返回 20000 个点，API 耗时历史最多 1000 条，端点 Top N 为 1 至 100。超限明确报错，不返回悄悄截断的“完整”结果。无效时间或粒度返回字段错误，数据库故障返回失败，不能被解释为没有历史数据。

## 写入与后台任务

### 页面与接口对应

资源表按当前页请求，搜索后回到第 1 页，删除最后一条后回到有效页码。页面丢弃切换条件前的过期响应，避免慢请求覆盖新结果。

| 资源 | v1 路径 | 页面行为 |
| --- | --- | --- |
| IP 组 | `/api/v1/ip-groups` | 服务端搜索名称、说明和成员，独立分页 |
| 黑白名单 | `/api/v1/ac/{whitelist或blacklist}/entries` | 分组和独立 IP 分页；展开组内成员每页显示 100 条 |
| 集群目标 | `/api/v1/lb/clusters/{clusterId}/destinations` | 只读取选中集群当前页，附带当前页异常状态 |
| 环境变量 | `/api/v1/param/env` | 单页加载和服务端搜索 |
| 插件 | `/api/v1/plugins` | 管理列表单页加载 |
| 证书文件 | `/api/v1/settings/certs` | 文件列表分页，运行状态摘要独立保留 |
| 管理角色 | `/api/v1/auth/roles` | 管理列表分页，用户编辑器保留角色选项 |
| API 耗时 | `/api/v1/timing/list` | 分页明细，保留全局统计摘要 |

黑白名单的 `total` 统计“组 + 独立 IP”条目数，不是展开后的 IP 数。已经由组包含的 IP 不再重复显示为独立条目；组的详情受 10000 条成员上限保护，页面不会一次创建全部成员 DOM。

集群选择器使用 `/api/v1/lb/cluster-options`，不加载所有目标详情。配置编辑器的完整配置、角色/插件选择选项和概览聚合不是资源表格；需要完整选项时客户端按接口分页读取，不把局部第一页冒充完整配置。插件内部列表协议由插件实现并受插件准入限制。

### 字段错误与发布校验

同步校验覆盖必填、长度、数量、数值范围、枚举、IP/CIDR、HTTP 地址、Header、路由格式和跨字段关系。字段路径使用 JSON 名称，例如 `route.routeId`、`ruleIds[0]`、`bypassPaths[0]`。Anti-Bot 例外目前只匹配单个 IP，填写 CIDR 会被拒绝；路径例外不能为空，防止空前缀意外放行全部路径。

通知渠道会分别返回地址、SMTP 主机和收发件人字段错误；站点 ID 与路由 ID 必须一致。依赖运行环境的校验仍在后台发布任务中完成，失败通过任务状态和日志返回，而不是将 202 当成成功。

补丁发布使用共享锁串行执行读、修改、保存和运行态验证。首次发布失败删除无效候选；已有配置恢复最近有效版本。恢复过程不继承已取消的 HTTP 请求令牌，避免客户端断开导致回滚中止。

### 幂等与审计

业务写接口支持 `Idempotency-Key`，长度 8 至 100，只允许 ASCII 字母、数字和短横线。同一凭据、同一键及相同请求可重放原结果；改变请求体、方法、路径或查询返回 409。记录仅在本进程保留十分钟，最多 128 项；响应超过 64 KiB 不缓存内容，再次提交会提示查询操作状态，不重复执行业务。

用户、角色和令牌管理也适用幂等保护。登录、会话刷新、修改自身密码和 MFA 一次性凭据流程不缓存响应。认证与二次验证在重放之前重新执行，幂等键不是权限凭据。

证书申请、续期与升级包校验已改为 HTTP 202，响应 `data.id` 为任务 ID。原设置页面会跳转任务中心。**202 只表示受理，不表示签发或升级已经成功**；脚本须查询任务终态。升级激活与回退仍属于进程排空和接管流程，与升级包准备是不同操作。

OpenAPI 从路由、请求 DTO、权限和显式响应元数据生成，支持同一路径多个方法、带约束的路径参数、属性命名、必填/长度/数值约束和可空引用。`TimeSpan` 使用 .NET 常量字符串格式，例如 `00:05:00`，不是 JSON 对象。同一状态的不同响应使用 `anyOf`，文件下载使用二进制模型。新增路由必须声明实际成功响应模型，不能依靠未声明模型的占位说明。

分发节点与运行状态复制使用独立 HMAC 认证，不使用控制台角色或 bearer token。运行状态复制额外要求 `X-LyWaf-Node`，签名字段顺序见 `runtimeStateSignature`。无长度头的报文也在读取过程中限制大小，重复签名头和复用 nonce 被拒绝。

## 插件边界

插件 API 通过 `MapLyWafPluginApi` 分派，不能绕开核心鉴权。`PluginApiAdmissionGate` 在进入插件前执行：

- 按 `Content-Length` 拒绝明显过大的请求；
- 按用户和插件限制一分钟窗口调用量；
- 对所有插件使用共享并发上限；
- 成功、拒绝和异常路径都释放并发租约；
- 调用与拒绝均进入审计日志。

这些限制保护控制进程，不替代插件内部的分页、流式读取、超时和输入验证。

## 验证方式

单元测试验证路径转换、JSON Schema `$ref`、错误字段以及三类插件限额。真实进程冒烟还应验证：

- `/api/v1/health/ready` 返回 200 和契约头；
- `/api/health/ready` 返回废弃头；
- 未认证 OpenAPI 返回结构化 401；
- 登录后 OpenAPI 包含核心端点与插件代理入口；
- `/api/v1/stop` 可以走正常托管停止流程。
