## 对外发布的博客专栏

## 面向开发者的参考

`01` 至 `14` 介绍项目、技术栈、架构、服务、中间件、插件、API、CLI、数据和部署；`15` 之后是面向实际搭建和运维的专题指南。

## 推荐阅读方式

- 第一次部署：`15 -> 16 -> 22 -> 23`。
- 安全策略：`17 -> 18 -> 20 -> 19`。
- 后端开发：`03 -> 05 -> 06 -> 09 -> 13`。
- 前端与插件：`10 -> 21 -> blog/plugins`。
- 发布博文：从 `blog/README.md` 按顺序阅读。

示例中的域名、端口和路径必须按实际环境替换。功能变化应同步更新技术参考、实战指南和博客；提交前检查相对链接、代码围栏和敏感信息。
