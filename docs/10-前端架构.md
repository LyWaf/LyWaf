# 前端架构

Web 管理控制台基于 Vue 3 + TypeScript + Tailwind CSS 构建。

## 主要页面

| 页面 | 功能 |
|------|------|
| Dashboard | 实时统计概览（图表） |
| Security | 安全策略配置 |
| FeatureStatus | 功能开关 |
| CcProtection | CC 规则管理 |
| InterceptEvents | 拦截事件查看器 |
| ApiTiming | API 性能分析 |
| ConfigEditor | YAML 配置编辑器 |
| ConfigOverview | 可视化配置浏览 |
| ClusterConfig | 后端集群管理 |
| RouteConfig | 路由配置 |
| FileServerConfig | 静态文件服务设置 |
| WafRules | WAF 规则编辑器 |
| SpeedLimit | 限速配置 |
| PluginManagement | 插件启停与设置 |
| PacketCapture | HTTPS 抓包管理 |
| GeoAccessPage | 地理访问控制 |
| IpControl | IP 封禁/放行 |
| ErrorTemplates | 自定义错误页模板 |
| GeneralSettings | 系统设置 |

## 状态管理（Pinia）

- 全局认证状态：token、用户名、过期时间
- 用户偏好设置
- 配置缓存
- UI 状态（弹窗、下拉等）

## HTTP 客户端（Axios）

- 自动注入 JWT Token
- 请求/响应拦截器
- 401 自动跳转登录页
- 可配置超时

## 路由

- Vue Router 路由与插件路由
- Meta 标签（标题、图标）
- 路由组件懒加载

## 目录职责

| 目录 | 职责 |
|---|---|
| `src/views` | 核心业务页面 |
| `src/components` | 跨页面通用组件 |
| `src/api` | Axios 实例、类型和核心 API |
| `src/stores` | Pinia 全局状态 |
| `src/router` | 核心路由和鉴权 |
| `src/plugins` | 插件独立路由、API 和页面 |

## 页面开发约定

页面必须覆盖加载、空数据、错误、超时和提交状态。慢操作使用局部 loading，删除和基线更新等危险操作需要确认。后端返回值必须有 TypeScript 类型，避免在模板中传播 `any`。

插件页面通过 `src/plugins/*/plugin.ts` 自动注册，所有后端请求走统一插件代理。不要把插件状态放进不相关的核心 Store，也不要在页面硬编码控制端地址。

## 构建与验证

```powershell
cd Frontend
npm install
npm run build
```

提交前验证桌面和窄屏、直接刷新路由、登录过期、接口超时和超长文本。构建通过只能证明类型与打包正常，关键工作流仍需浏览器端到端检查。
