# 前端架构

Web 管理控制台基于 Vue 3 + TypeScript + Tailwind CSS 构建。

## 页面（23 个视图）

| 页面 | 功能 |
|------|------|
| Dashboard | 实时统计概览（图表） |
| Security | 安全策略配置 |
| FeatureStatus | 功能开关 |
| CcProtection | CC 规则管理 |
| InterceptEvents | 拦截事件查看器 |
| ApiTiming | API 性能分析 |
| ConfigEditor | YAML 配置编辑器 |
| ConfigOverview | 可视化配置浏览 |
| ClusterConfig | 后端集群管理 |
| RouteConfig | 路由配置 |
| FileServerConfig | 静态文件服务设置 |
| WafRules | WAF 规则编辑器 |
| SpeedLimit | 限速配置 |
| PluginManagement | 插件启停与设置 |
| PacketCapture | HTTPS 抓包管理 |
| GeoAccessPage | 地理访问控制 |
| IpControl | IP 封禁/放行 |
| ErrorTemplates | 自定义错误页模板 |
| GeneralSettings | 系统设置 |

## 状态管理（Pinia）

- 全局认证状态：token、用户名、过期时间
- 用户偏好设置
- 配置缓存
- UI 状态（弹窗、下拉等）

## HTTP 客户端（Axios）

- 自动注入 JWT Token
- 请求/响应拦截器
- 401 自动跳转登录页
- 可配置超时

## 路由

- Vue Router hash 模式（`#/page`）
- 23 个路由定义
- Meta 标签（标题、图标）
- 路由组件懒加载
