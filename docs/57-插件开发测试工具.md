# 插件开发测试工具

`LyWaf.PluginTesting` 是独立测试辅助包，只依赖 `LyWaf.PluginSdk` 和 ASP.NET Core 共享框架。它不会启动完整 LyWaf，也不会连接 DuckDB。

```csharp
await using var host = new PluginTestHost(new MyPlugin(), timeout: TimeSpan.FromSeconds(2));
await host.StartAsync();

var pipeline = host.BuildProxyPipeline(ctx => Task.CompletedTask);
await pipeline(new DefaultHttpContext());

var response = await host.ExecuteApiAsync("status");
Assert.Equal(200, response.Response.StatusCode);
await host.StopAsync();
```

`PluginTestHost` 按真实顺序执行 `ConfigureServices -> InitializeAsync -> StartAsync -> StopAsync`，可构造代理管道并完整执行 `IResult`，每个异步阶段都有超时。自动创建的数据目录会在释放时删除，因此可以断言插件是否关闭后台任务和文件句柄。

`PluginTestPayloads.CreateGeneratedStream` 可生成 GB 级逻辑流而不在内存中构造完整内容，用于大文件和流式处理测试。`PluginTestQueue<T>` 使用固定容量 Channel，可断言满载拒绝、完成通知和停止排空。慢远端可用不完成的测试处理器模拟，并通过宿主超时断言不会无限阻塞。

项目内的 `PluginTestHostTests` 展示了生命周期、管道顺序、统一 API、大文件、慢操作、有界队列和停止清理的完整测试方式。
