# 部署

## 部署模式

| 模式 | 说明 |
|------|------|
| 完整 WAF | 反向代理 + 全部防护启用 |
| 文件服务 | 静态文件服务 + WAF 防护 |
| 快速代理 | 一行命令启动反向代理 |
| Mock 服务 | API 响应 Mock（开发/测试） |
| 负载均衡 | 纯负载均衡（不启用 WAF 规则） |
| VPN 网关 | SoftEther L2TP/IPSec VPN 服务 |
| 后台服务 | Windows 服务 / Linux systemd |

## 系统要求

- .NET 9.0 Runtime
- 支持 OS：Windows、Linux、macOS、FreeBSD
- 端口：可配置（默认 HTTP 80、HTTPS 443、控制台 5555）
- VPN：需单独安装 SoftEther VPN Server
- ACME：需公网 80 端口可达（HTTP-01 Challenge）

## 防火墙端口

| 端口 | 协议 | 服务 |
|------|------|------|
| 80 | TCP | HTTP（反向代理、ACME Challenge） |
| 443 | TCP | HTTPS（反向代理、SSTP VPN） |
| 5555 | TCP | 控制台 API |
| 500 | UDP | IPSec IKE（VPN） |
| 4500 | UDP | IPSec NAT-T（VPN） |
| 1701 | UDP | L2TP 隧道（VPN） |
