# 项目概述

LyWaf 是基于 .NET 9.0 / ASP.NET Core 构建的 **Web 应用防火墙（WAF）与反向代理平台**，集流量防护、智能路由、实时分析和管理控制台于一体。

## 核心能力

- **反向代理** — YARP 引擎，多协议多后端路由
- **WAF 引擎** — 自定义规则的攻击检测与拦截
- **CC/DDoS 防护** — 高级限速 + 行为分析
- **访问控制** — IP 黑白名单、地理封锁（IP2Region）
- **IP 组** — 可复用 IPv4/IPv6/CIDR 分组，集中维护访问策略
- **ACME/Let's Encrypt** — 自动 SSL 证书签发与续期
- **负载均衡** — 8+ 算法（一致性哈希、A/B 测试等）
- **正向代理** — HTTP/HTTPS/SOCKS5，支持 PCAP 抓包
- **Stream 转发** — TCP 非 HTTP 协议代理
- **插件系统** — 可扩展的中间件与管线钩子
- **网页防篡改** — 按网站和路径维护基线，目录规则惰性收集
- **CORS** — 站点/路径级跨域策略与 OPTIONS 预检处理
- **实时分析** — DuckDB 嵌入式统计 + 仪表板
- **Web 控制台** — Vue 3 前端，配置与监控一体

## 典型部署位置

LyWaf 位于客户端与源站之间。公网请求先到 LyWaf，经过监听匹配、访问控制、WAF、CC 防护和限速，再由 YARP 转发到一个或多个上游。控制台使用独立控制端口，不应与公网业务入口混用。

```text
客户端 -> LyWaf 80/443 -> 安全中间件 -> YARP -> 应用集群
管理员 -> LyWaf 控制端口 -> 认证 -> REST API / Vue 控制台
```

## 适用与不适用场景

适合需要自托管反向代理、可编程安全策略、多上游路由和本地分析的团队。LyWaf 不是云清洗中心，单机部署不能替代运营商级 DDoS 清洗；面对超出链路容量的攻击，仍需结合 CDN、云防护或上游 ACL。

## 最小验收标准

完成安装后应确认业务域名能经 LyWaf 到达上游、控制端口未暴露公网、错误请求可在日志中定位、配置重载有明确结果，并实际演练一次优雅停止和重新启动。
