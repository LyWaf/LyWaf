# 静态文件服务

LyWaf 的 `file_server` 直接从本地目录提供文件，适合前端资源、下载文件和只读站点。路径解析、安全检查和 HTTP 条件语义由 `FileService` 完成；实际发送由 `FileProviderMiddleware` 负责。

## 配置

```ly
static.example.com {
    /assets/* {
        file_server {
            root = "./public"
            index = ["index.html", "index.htm"]
            browse = false
            max_browse_entries = 1000
            max_file_size = 104857600
            precompressed = true
            follow_links = false
            show_hidden = false
            cache_control = "public, max-age=3600"
            denied_extensions = [".config", ".env", ".key", ".pem", ".db", ".duckdb", ".log", ".bak"]
        }
    }
}
```

`max_file_size` 的单位是字节。`denied_extensions` 显式配置时是完整拒绝列表；不要遗漏私钥、环境变量、数据库、日志和备份文件。`follow_links` 只有在确认链接目标也受控时才能开启。

## HTTP 行为

- 只接受 GET 和 HEAD；其他方法返回 405 与 `Allow: GET, HEAD`。
- HEAD 返回与 GET 相同的状态和实体头，但不发送正文。
- 支持单段、后缀和最多 16 段 Range。单段返回 `Content-Range`，多段使用 `multipart/byteranges`，完全越界返回 `416 bytes */长度`。
- `If-None-Match` 优先于 `If-Modified-Since`；匹配时返回带 ETag、Last-Modified 和 Cache-Control 的 304。
- `If-Range` 匹配时发送区间，不匹配时降级为完整 200 响应。
- 所有文件响应设置 `X-Content-Type-Options: nosniff`。

## 路径安全

请求路径经 `Path.GetFullPath` 规范化后，必须等于根目录或位于“根目录 + 分隔符”之下，因此 `..` 和同名前缀目录不能越界。默认拒绝路径中以点开头的段、Windows Hidden 属性、符号链接和重解析点。

目录浏览复用同一套过滤规则，不会把无法直接访问的敏感项列出来。列表采用惰性枚举，并由 `max_browse_entries` 限制为 1 至 10000 项，防止超大目录制造一次性内存峰值。文件名显示经过 HTML 编码，链接段经过 URL 编码。

## 发送与取消

完整文件和单段 Range 通过 ASP.NET Core `SendFileAsync` 发送。Kestrel 和宿主可在明文 HTTP/1.1、受支持平台等条件下选择优化的文件发送路径；TLS、HTTP/2、HTTP/3 或宿主限制下可能退化为异步流复制，因此这里不承诺所有连接都使用内核零拷贝。

多段 Range 逐段调用文件发送接口，只在内存中保存少量区间和边界文本，不拼接完整文件。所有发送都传入 `RequestAborted`，客户端下载中断后停止继续读取。

## 预压缩

开启 `precompressed` 后，LyWaf 根据 `Accept-Encoding` 的质量值选择 `.br`、`.zst` 或 `.gz` 同名文件，质量相同时优先 br、zstd、gzip。质量为 0 的编码不会使用。响应保留原文件 MIME，并设置 `Content-Encoding` 与 `Vary: Accept-Encoding`。

预压缩文件必须由构建流程正确生成，不能只是改扩展名。动态响应压缩中间件应保持关闭或识别已有 `Content-Encoding`，避免重复压缩。

## 缓存策略

`cache_control` 原样写入文件和 304 响应。带内容指纹的静态资源可使用 `public, max-age=31536000, immutable`；入口 HTML 通常使用较短 TTL 或 `no-cache`。该浏览器缓存策略与反向代理响应缓存相互独立。

## 验证

```powershell
curl.exe -I http://127.0.0.1:8080/assets/app.js
curl.exe -H "Range: bytes=0-99" -i http://127.0.0.1:8080/assets/app.js
curl.exe -H "Range: bytes=0-9,100-109" -i http://127.0.0.1:8080/assets/app.js
curl.exe -H "Accept-Encoding: br, gzip" -I http://127.0.0.1:8080/assets/app.js
```
