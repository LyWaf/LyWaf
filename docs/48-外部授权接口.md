# 外部授权接口

外部授权在请求通过本地 WAF、访问控制、CC 和限速后、进入上游前调用独立授权服务。它适合把组织级身份、租户和细粒度权限决策集中到一个服务，而不是把远程授权逻辑写进每条 WAF 规则。

## LyWaf 配置

全局部分定义网络和数据边界：

```ly
ExternalAuthorization {
    Endpoint = "https://auth.internal.example/check"
    TimeoutMilliseconds = 1000
    MaxBodyBytes = 8192
    MaxHeaderBytes = 16384
    MaxResponseBytes = 65536
    FailOpen = false
    CacheSeconds = 0
    MaxCacheEntries = 10000
    AllowedRequestHeaders = ["Authorization", "Cookie", "Content-Type"]
    AllowedUpstreamHeaders = ["X-Authenticated-User", "X-Authenticated-Groups"]
    CacheKeyHeaders = ["Authorization"]
}
```

站点或路径显式启用：

```ly
api.example.com {
    /private/* {
        ExternalAuth {
            Enabled = true
            TimeoutMs = 800
            FailOpen = false
            CacheSeconds = 5
        }
        reverse_proxy http://application.internal
    }
}
```

Route 可覆盖 Endpoint、超时、正文上限、FailOpen 和缓存时间。没有 `ExternalAuth` 的 Route 不发起授权调用。

## 请求协议

LyWaf 向 Endpoint 发送 JSON：

```json
{
  "method": "GET",
  "scheme": "https",
  "host": "api.example.com",
  "path": "/private/orders?id=42",
  "headers": { "Authorization": ["Bearer ..."] },
  "bodyBase64": null,
  "bodyTruncated": false
}
```

只发送 `AllowedRequestHeaders`。正文按 Base64 传输，并且只在不超过 `MaxBodyBytes` 时发送；超限时正文为空且 `bodyTruncated=true`。Header 总量、请求正文和授权响应分别有硬上限。

授权服务成功时返回 2xx 和以下 JSON：

```json
{
  "allowed": true,
  "statusCode": 403,
  "reason": null,
  "headers": {
    "X-Authenticated-User": "user-42"
  },
  "cacheSeconds": 5
}
```

`allowed=false` 时 LyWaf 使用 400 到 599 范围内的 `statusCode`，默认 403。授权服务返回的 Header 只有出现在 `AllowedUpstreamHeaders` 时才写入原请求，不能任意覆盖 Host、Authorization 或转发身份。

## 失败与缓存

超时、非 2xx、无效 JSON 和超限响应都视为授权服务失败。`FailOpen=false` 返回 503，是安全默认值；`true` 会绕过授权继续回源，只适用于可接受短期降级的低风险接口。

缓存键包含 Route、方法、Host、Path、正文和 `CacheKeyHeaders`，最终只保存 SHA-256 摘要，不保存 Token/Cookie 明文。缓存是有界进程内缓存，授权服务返回的 `cacheSeconds` 不能超过 Route 上限。权限撤销敏感场景应关闭缓存或使用很短 TTL。

`lywaf_ext_auth_requests_total` 和 `lywaf_ext_auth_request_duration_seconds` 同时导出到 Prometheus/OpenMetrics 与 OTLP。结果标签是固定集合，不包含 Endpoint、用户名、Token、Cookie、Path 或拒绝原因。
