# 高级负载均衡

`Advanced` 策略把 Priority/Failover、Region/Zone、Subset 和慢启动放在一个确定的选择顺序中。它接收的候选集已经由 YARP 主动健康、被动健康和 LyWaf Outlier Detection 过滤，因此不会为了地域或子集重新选入已标记不可用的实例。

## 配置

```ly
api.example.com {
    proxy {
        to {
            east-a {
                Address = "http://10.0.0.1:8080"
                Priority = 0
                Region = east
                Zone = a
                Subset = stable
                Weight = 10
                SlowStartSeconds = 30
            }
            west-backup {
                Address = "http://10.0.1.1:8080"
                Priority = 1
                Region = west
                Zone = b
                Subset = stable
            }
        }
        AdvancedLb {
            RegionHeader = X-LyWaf-Region
            ZoneHeader = X-LyWaf-Zone
            SubsetHeader = X-LyWaf-Subset
            SubsetKey = Subset
            SubsetFallback = Any
            SlowStartSeconds = 60
        }
        health_check {
            Active { Enabled = true Policy = Lyx Interval = "00:00:05" Timeout = "00:00:02" }
        }
        outlier_detection { Enabled = true ConsecutiveFailures = 3 }
    }
}
```

命名 Destination 配置会保留 `Weight`、`Priority`、`Region`、`Zone`、`Subset` 和 `SlowStartSeconds` Metadata。`AdvancedLb` 自动设置 Cluster 的 `LoadBalancingPolicy = Advanced`。

## 选择顺序

1. YARP 移除主动/被动健康状态不可用的 Destination。
2. 在剩余实例中只保留最小 `Priority`。Priority 0 全部不可用后才使用 Priority 1，实现故障切换。
3. 请求含配置的 Region Header 且存在匹配实例时，优先该 Region；无匹配时回退当前集合。
4. Zone 使用相同的“有匹配则收窄、无匹配则回退”规则。
5. Subset Header 匹配 Destination 的 `SubsetKey`。`SubsetFallback = Any` 无匹配时回退；`None` 返回无可用目标。
6. 对最终候选按 `(ConcurrentRequests + 1) / EffectiveWeight` 选择分数最低者。

Region、Zone 和 Subset Header 应由可信入口、服务身份层或 LyWaf Header 转换写入。不要直接信任公网客户端提供的同名 Header，否则客户端可能自行选择部署区域或灰度子集。

## 慢启动

新实例首次进入候选集时，有效 Weight 从配置 Weight 的 5% 起步，并在 `SlowStartSeconds` 内线性增长到完整值。Destination 自己的 `SlowStartSeconds` 优先于 Cluster 默认值。该机制减少刚启动实例在缓存、JIT 和连接池尚未预热时突然承受完整流量的风险。

慢启动不是健康检查。实例仍必须先通过主动健康，运行中的连接失败和 5xx 仍由被动健康及 Outlier Detection 处理。动态发现只替换 Destination 配置，不直接改写这些健康状态。
