# 中间件管线

HTTP 请求处理管线由 14 个中间件按严格顺序执行：

| 顺序 | 中间件 | 功能 |
|------|--------|------|
| 1 | BandwidthCounting | 追踪每个请求的入/出流量 |
| 2 | ResponseCompress | 响应压缩（gzip, brotli, zstd） |
| 3 | Plugin（高优先级） | 安全关键型插件中间件 |
| 4 | AccessControl | IP 黑白名单、地理封锁、连接数限制 |
| 5 | IpLog | 按 IP 记录请求日志 |
| 6 | AutoHttps | 强制 HTTP → HTTPS 重定向 |
| 7 | WafControl | 应用 WAF 规则（攻击模式匹配） |
| 8 | Captcha | 可疑流量触发验证码 |
| 9 | CcProtection | CC 攻击检测与封锁 |
| 10 | Throttled | 请求节流 |
| 11 | SpeedLimit | 限速执行 |
| 12 | CcResponseMonitor | CC 响应模式监控 |
| 13 | Plugin（低优先级） | 非关键型插件中间件 |
| 14 | SimpleRes / FileProvider | Mock 响应或静态文件服务 |

中间件处理完成后，请求转发至 YARP 反向代理引擎进行路由和负载均衡。
