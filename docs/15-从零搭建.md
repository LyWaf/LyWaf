# 从零搭建 LyWaf

## 1. 目标拓扑

```text
浏览器/客户端 -> LyWaf :80/:443 -> 业务服务 :8080
                         |
                         +-> 控制台 127.0.0.1:7030
```

LyWaf 位于业务服务之前，负责 TLS、路由、WAF、访问控制、限速、统计和插件处理。业务服务应尽量只允许 LyWaf 所在主机或网段访问。

## 2. 环境准备

- 安装 .NET 9 SDK；仅运行发布包时安装 ASP.NET Core Runtime 9。
- 安装 Node.js 20 或更高版本，仅在需要重新构建前端时使用。
- 确认入口端口未被其他程序占用。
- Windows 使用 PowerShell；Linux 使用具有工作目录写权限的普通用户。

```powershell
dotnet --info
node --version
git clone <repository-url> LyWaf
cd LyWaf
```

## 3. 编译

后端编译：

```powershell
dotnet restore
dotnet build -c Release
```

前端发生改动时执行：

```powershell
cd Frontend
npm install
npm run build
cd ..
```

`npm run build` 会将产物同步到 `control_html`，后端从该目录提供控制台页面。

发布独立目录：

```powershell
dotnet publish -c Release -o publish
Copy-Item config.ly.example publish/config.ly
```

## 4. 最小配置

将以下内容保存为 `config.ly`：

```ly
http_port = 80
control_listen = "127.0.0.1:7030"

example.com {
    HeaderUps {
        X-Real-IP = "{ClientIp}"
        X-Forwarded-For = "{ClientIp}"
        X-Forwarded-Proto = "{Scheme}"
    }
    proxy = ["http://127.0.0.1:8080"]
}
```

先保证 HTTP 代理工作，再增加 HTTPS、安全规则和插件。这样可以把“上游不可达”和“防护策略拦截”分开排查。

## 5. 启动和验证

```powershell
dotnet LyWaf.dll run -c config.ly
```

源码目录也可使用：

```powershell
dotnet run -- run -c config.ly
```

验证代理：

```powershell
curl.exe -i -H "Host: example.com" http://127.0.0.1/
```

首次打开 `http://127.0.0.1:7030` 时使用程序生成的控制台凭据。忘记密码可执行：

```powershell
dotnet LyWaf.dll reset password
```

## 6. 配置 HTTPS

已有 PEM 证书时：

```ly
https_port = 443

Certs {
    example.com {
        PemFile = "certs/example.com.pem"
        KeyFile = "certs/example.com.key"
    }
}
```

证书私钥必须仅允许运行 LyWaf 的账号读取。自动证书签发见 `config.ly.example` 的 `Acme` 段；HTTP-01 模式要求公网 80 端口可达。

## 7. 上线顺序

1. 仅启用反向代理，验证业务全部路径、WebSocket 和上传下载。
2. 配置真实客户端 IP 请求头，确认应用日志中的来源地址。
3. 开启统计和仅观察型 WAF 规则，检查误报。
4. 逐步启用拒绝、封禁、CC、限速和验证码。
5. 配置网页防篡改时先建立少量精确路径基线，再扩展目录规则。
6. 完成备份、日志轮转、健康检查和回滚演练。

## 8. 成功标准

- 入口请求只经过 LyWaf，业务端口不直接暴露公网。
- HTTP/HTTPS、域名和证书匹配正确。
- 控制台只监听本机或受控管理网。
- 重启后配置、IP 组、插件数据、统计数据和防篡改基线仍存在。
- 上游失败、规则误报和证书过期均有明确告警与处理流程。

## 9. 最小安全加固

控制台绑定本机或管理网并设置强认证，源站只接受 LyWaf 来源，私钥仅服务账号可读。WAF、CC 和限速从观察开始，先记录正常峰值和误报，再逐项阻断。真实客户端 IP 必须在访问控制前配置正确。

## 10. 回滚准备

保留最小可用配置和上一发布目录。每增加一类功能就验证并记录配置版本；故障时先恢复上一配置，不要同时修改路由、证书和安全规则。
