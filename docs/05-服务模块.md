# 服务模块

## WAF 引擎（WafRule/）

自定义规则的 Web 应用防火墙，检测并拦截攻击。

- 正则匹配请求模式（URI、Headers、Body）
- 内置系统规则（SystemWafRules）覆盖常见攻击模式
- REST API + Web 控制台管理自定义规则
- 规则存储于 `.lywaf.rules.json`
- 实时更新，无需重启

## CC/DDoS 防护（Statistic/）

高级 CC 攻击检测与缓解。

- 可配置时间窗口的请求计数
- AdvancedCcRule：复合多条件规则
- CcRuleChecker：实时规则评估引擎
- 自动 IP 封禁，阈值与时长可配置
- 基于模式的检测（URI、User-Agent、Headers）
- Web 控制台 CRUD 管理

## 访问控制（AccessControl/）

- IP 黑白名单（支持 CIDR 子网）
- IP2Region 地理封锁（国家/省份级别）
- 单 IP 连接数限制（ConnectionLimitConfig）
- 热更新动态规则

## 正向代理（ProxyServer/）

支持多协议的全功能正向代理。

- HTTP 代理（CONNECT 隧道）
- HTTPS 代理（TLS 拦截 / PCAP 模式）
- SOCKS5 代理（带认证）
- 协议自动检测（首字节探测）
- WebSocket 升级处理（HTTP 101 Switching Protocols）
- PCAP 抓包（自定义 CA 证书，PcapCertProvider）

## Stream 服务（StreamServer/）

非 HTTP 协议的 TCP 流转发。

- StreamService：BackgroundService 管理 TCP/UDP 监听与连接生命周期
- StreamHandler：TCP 预读、选路、限速和双向数据中继
- UdpStreamProxy：有界 UDP 客户端会话与数据报转发
- 上游目标健康检查
- 可配置超时与缓冲区

## ACME/Let's Encrypt（Acme/）

- HTTP-01 Challenge 自动证书签发
- 证书续期自动化
- 多域名（SAN）证书支持
- 与 Kestrel TLS/SNI 集成

## 分析系统（DuckDb/）

嵌入式 DuckDB 数据库，持久化统计与分析。

- DuckDbService：连接管理
- DuckDbQueryService：查询构建与执行
- StatisticFlushService：内存数据定期持久化
- StatisticRecoveryService：启动时数据恢复
- DataRetentionService：过期数据自动清理
- RuntimeLogService：事件日志

## 服务设计约定

高频请求服务应避免同步磁盘和远程 I/O。中间件只进行匹配、计数或有界入队，后台服务批量持久化。共享可变状态使用并发集合或明确锁，不能依赖普通 Dictionary 在多请求下“通常没问题”。

外部网络调用统一使用 `HttpClientFactory`、超时和取消令牌；大响应使用 `ResponseHeadersRead` 和流式处理。数据库写入尽量批量化，查询接口限制时间范围、结果数量和并发。

## 依赖关系原则

- 中间件依赖服务接口，不直接操作配置文件。
- 服务通过 Options 读取配置，不自行重复解析 LY。
- 控制 API 调用服务，不复制业务规则。
- 后台服务停止时释放 Channel、连接、计时器和文件句柄。
- 插件服务只写插件专属数据目录。

## 模块排障顺序

先确认配置是否绑定，再确认服务是否注册和启动，之后观察队列、数据库或网络依赖，最后检查页面展示。服务启动日志正常不等于功能正常，应使用一个最小请求验证数据从中间件进入服务并最终持久化。

新增模块时至少提供配置模型、服务接口、实现、DI 注册、日志、取消处理和测试；若进入请求管线，还需记录执行位置和短路条件。
